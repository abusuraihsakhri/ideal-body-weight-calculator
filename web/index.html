Batch CSV calculator

Select a local CSV to compute all four formulas and export results. No file is uploaded or stored by this page. Avoid including names, medical record numbers or other identifiable patient data.

CSV format and accepted units

Required columns: sex,height_cm,weight_kg. Optional: patient_id,weight_unit. Units for weight_unit: kg (default), lb, lbs, pound, pounds. Use anonymous row labels only.
